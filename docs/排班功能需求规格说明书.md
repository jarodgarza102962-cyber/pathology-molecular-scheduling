# 1. 概述

本模块用于病理科实验室与分子病理实验室对科室人员排班、工位调度、岗位规则维护以及排班任务执行协同进行统一管理。系统以 **“岗位能力准入、周期矩阵编排、待办任务自动派发、全员执行协同与闭环核销”** 为核心闭环，全面解耦检测岗位、实验方法、检测靶标与日常辅助杂务，满足 CNAS-CL02 及病理实验室质量管理体系中关于人员技术资质准入、关键岗位双签质控、房间安全巡检及日常职责溯源的管理要求。

* **原型设计稿文件**：[病理科与分子科排班系统高保真原型.html](file:///d:/lee/ai应用文档/人员管理/prototypes/病理科与分子科排班系统高保真原型.html)
* **关联需求**：
  * **需求XQ_261027001**：分子科四层排班解耦与多轨并行。分子实验室日常涉及高通量测序(NGS)、荧光原位杂交(FISH)、Sanger重排测序、荧光定量PCR等多条复杂技术路线，且包含季度工位轮换、长期物料A/B角包干及11人轮转7个物理房间的安全巡检。系统将“检验项目”、“实验工位”与“辅助杂务（如切蜡块、转运送检）”分轨运行与独立统计。
  * **需求XQ_261027002**：资质白名单准入与自动防呆。读取人员技术档案与授权结果，未经授权人员不得排入特定岗位；对关闭兼任的主技术岗位执行同日互斥拦截，对日常辅助类岗位放行并行兼任。
  * **需求XQ_261103001**：排班与任务闭环联动。排班发布后，支持一键发起排班待办，系统依据岗位绑定的工作指引及任务模板批量实例化为个人待办日程清单，并在独立的“待办任务”工作台支持组长与员工实时跟踪进度与闭环打勾。

## 1.1 业务背景与科室排班特征
1. **病理科（临床业务任务调度型）**：以诊断任务与会诊任务为调度中心。日常由送检标本量和病理切片类型触发，排班分为按工作日/院区分布的诊断常规岗位，以及按专家个人分配的会诊、质控和带教任务。核心业务处理为任务指派与工作量/津贴核算。
2. **分子科（实验室流程与能力调度型）**：以合规资质与多维职责覆盖为调度中心。分子实验室具有强流程性与严苛的质量合规（如 ISO 15189）要求。日常运作包含检测工位、季度技能轮换、长期辅助与质控责任（A/B 双人负责制）以及每日物理房间安全巡视（平移轮转）。核心业务处理为人员胜任能力匹配与多维职责覆盖。

## 1.2 核心业务解耦原则
1. **概念四层解耦**：岗位/工位(Post) ≠ 检测方法(Method) ≠ 检测项目/靶标(Item) ≠ 辅助任务(AuxTask)。辅助任务（如切蜡块、转运、试剂盘点、SOP等）独立建库管理，单独指派与统计，不计入临床检验项目量。
2. **同名异法独立建项**：同一临床靶标因检测方法不同而分属不同工位时，独立建项。如 WT1 拆分为 `WT1-PCR` (归属PCR岗) 与 `WT1-FISH` (归属FISH分析岗)；`PDGFRA突变(PCR)` 与 `PDGFRA/KIT(测序)` 拆分管理。
3. **轻量资质匹配**：资质映射为岗位与人员的“胜任池（competent_pool）”，在排班时作为前置下拉过滤依据。
4. **多轨并行与平移解耦**：检测主班岗、A/B辅助质控责任、物理房间巡检三轨并行解耦，独立平移轮换。

# 2. 功能页面一：综合排班工作台（大看板）

页面用于展示全科室全景排班矩阵、大周期批量排班统筹以及一键发起待办任务派发。

## 2.1 顶部控制栏

### 2.1.1 筛选区
1. **日期选择器**：
   - 控件类型：紧凑型年月选择组件（支持选年月与前/后年份面板切换）。
   - 默认展示：默认展示当前年月（如 `2026年 11月`）。
   - 联动规则：
     - 顶部始终固定选年月，格式不随下方切换而改变；
     - 修改年月后，大盘按当前模式自动刷新（按日刷当月，按月/按季刷当年，所选月高亮）；
     - 同步更新右栏【辅助岗位】生效周期。
2. **岗位大类**：
   - 控件类型：下拉选择框。
   - 选项内容：全部岗位大类、分子检测技术、分子项目审核与报告、常规技术、常规病理诊断、样本与流转管理、试剂/设备/物料管理、质量与安全管理。
   - 默认状态：默认选中“全部岗位大类”。
   - 联动规则：切换时过滤排班矩阵中的岗位大类分组行，非所选大类岗位隐藏。
3. **专业组**：
   - 控件类型：下拉选择框。
   - 选项内容：全科室 / 全部专业组、分子检测组、取材技术组、常规病理诊断组。
   - 默认状态：默认选中“全科室 / 全部专业组”。
   - 联动规则：与岗位大类叠加过滤，仅展示匹配专业组的岗位行。
4. **人员高亮定位**：
   - 控件类型：下拉选择框。
   - 选项内容：包含科室全部在职人员姓名。
   - 默认状态：默认选中“请选择”。
   - 联动规则：选中具体人员后，矩阵中所有包含该人员的单元格高亮显示，其余单元格弱化显示；选择“请选择”恢复默认显示。
5. **排班状态展示徽章**：
   - 控件类型：状态徽章标识（位于顶部筛选区时间切换旁）。
   - 状态枚举：
     - **【已发布】**（绿色徽章）：当前周期排班已正式发布生效；
     - **【草稿】**（橙黄色徽章）：当前周期排班已执行批量排班暂存，尚未正式发布；
     - **【未排班】**（灰色徽章）：当前周期尚未编制排班。
   - 联动规则：每一次时间筛选切换（选年月、年份或时间段），顶部实时联动更新并展示当前周期排班表的最新状态。

### 2.1.2 操作区
顶部左侧常驻 4 个纯文字操作按钮，按高频使用习惯排布：
1. **【发起待办】**：
   - 控件样式：主蓝实心按钮（高频主操作）。
   - 使用条件：具有按钮权限。
   - 处理逻辑：点击打开【发起待办】弹窗 (`#modalLaunchTodo`)，默认带入当前大盘周期起止日期并扫描有效排班岗位，用于将当前排班网格正式批量实例化派发为员工待办清单（详细规格参见第 3.4 节）。
2. **【批量排班】**：
   - 控件样式：主蓝实心按钮（周期统筹主操作）。
   - 使用条件：具有按钮权限。
   - 处理逻辑：点击打开【批量排班安排】全景工作台 (`#modalBatchSchedule`)。
3. **【单日排班】**：
   - 控件样式：白底灰线框按钮。
   - 使用条件：常驻可用。
   - 处理逻辑：点击激活单日排班微调交互模式，亦支持直接在排班网格中双击/点击对应单元格唤起【单日排班】弹窗（详细规格参见第 2.3 节）。
4. **【排班规则维护】**：
   - 控件样式：白底灰线框按钮。
   - 使用条件：具有按钮权限。
   - 处理逻辑：点击打开【岗位与排班规则维护中心】弹窗 (`#ruleConfigPageOverlay`)。

## 2.2 排班大盘展示区（左右两栏）

排班大盘主体采用**左右两栏并列协同布局**：
* **左栏【岗位排班】**（占比约 2/3）：负责全科临床检测工位、常规任务的高频时间轴编排与推演；
* **右栏【辅助岗位】**（占比约 1/3）：负责收试剂、设备管理、标本转运、室内质控等常态化保障与质量安全职责的协同展示与 A/B 角互备。

### 2.2.1 左侧：岗位排班区

#### 1. 操作区功能
1. **【展开全部项目】**：常驻操作按钮（`#btnToggleAllExpand`，位于左栏标题右侧）。
   - 点击触发全局折叠/展开：在各岗位名称下方展开或收起其绑定的具体检测靶标细项行（如 PCR 岗下展开肺11、肠四联、BRAF 等）；
   - 展开状态下按钮切换为 `[▲ 收起全部项目]`，再次点击还原为精简单行岗位视图。
2. **视图模式切换（周期切换胶囊）**：
   - 控件类型：微胶囊分段单选按钮组（位于左栏标题栏最右侧，提供【按日】/【按月】/【按季度】三档，默认选中【按日】）。
   - 联动规则：
     - **【按日】**：展开当月逐日排班网格（横轴按周次展开具体日期）；
     - **【按月】**：继承年份展开整年 1-12 月，查看各工位全年主责人员，所选月份高亮；
     - **【按季度】**：继承年份平铺展开 Q1~Q4 四个季度列，用于季度错位轮岗；
     - 切换时仅改变大盘展示粒度，不改变顶部日期选择器格式。

#### 2. 表格区域功能
1. **固定列（岗位信息）**：靠左固定冻结。
   - 包含岗位名称加粗文本、专业组与岗位类型标签、关联任务/项目明细（项目间使用 `·` 分隔，超长单行省略带悬浮提示；支持通过展开按钮在下方展开细项项目子行）。
2. **横向表头与网格结构（随视图模式自适应切换）**：
   - **【按日模式】（默认工作模式）**：
     - 表头为双层置顶冻结表头：第一层按自然月合并展示，第二层展示具体日期与星期，区分“今天”高亮列标识、工作日 `[班]` 与公休日 `[休]` 角标；数据源严格对接系统后台【日历设置-工作时间规划设置】（sz日历）；
     - 网格按日展开当月各天，单元格内展示日度实际在岗人员姓名标签；未排班展示空；
     - 适用于日常排班精细管理与宏观通览。
     ![图 2-1 排班工作台日度矩阵全景大看板](./images/schedule_features/01_schedule_board_day_view.png)
   - **【按月模式】（年度总览模式）**：
     - 表头为年度置顶表头，横向自适应平铺展开整年度 12 个月份（1月 至 12月）；
     - 单元格内呈现各工位在当月的主责人员；如果一个月内有多位责任人，汇总在同一格内展示；
     - 适用于长期人员覆盖与年度培养通览。
     ![图 2-2 排班工作台全年度月度总览看板](./images/schedule_features/02_schedule_board_month_view.png)
   - **【按季度模式】（季度轮岗统筹模式）**：
     - 表头展示整年度 Q1、Q2、Q3、Q4 四个季度周期；
     - 单元格内呈现各岗位在该季度的骨干负责人，清晰支撑分子实验室季度错位轮岗。
3. **单元格展示规则（人数阶梯自适应与溢出气泡）**：
   - **单人（1 人）**：单元格居中展示 1 个标准的纯文本药丸标签（如 `张明`），鼠标悬浮 Tooltip 提示完整姓名；
   - **双人（2 人）**：采用垂直紧凑堆叠布局（上下各 1 个姓名标签，如上方 `张明`、下方 `李华`），悬浮展示全部名单；
   - **三人及以上（≥3 人）**：单元格内最多直接展示前 2 位人员姓名标签，第 2 位标签后紧随一个浅蓝底数字气泡角标（如 `李华` `+1`）；鼠标悬浮单元格或气泡触发 Tooltip 浮层展示完整人员姓名（逗号隔开）；
   - **空缺格（0 人）**：显示浅灰色 `+ 点击排班` 提示（未排班展示空/占位符）；
   - **周末公休格**：表头带公休日 `[休]` 角标，单元格背景标识为公休灰色，默认不排班。

### 2.2.2 右侧：辅助岗位区

#### 1. 操作与联动说明
1. **继承全局时间上下文（无独立日期列）**：
   - 辅助岗位表**不设置独立的日期/时间跨度列**，直接继承并联动顶部全局筛选器（`年月`）；
   - 仅呈现当前所选时间段内实际生效的辅助岗位排班人员，彻底解耦左右两侧表格在时间粒度上的冲突。

#### 2. 表格区域说明
1. **极简两列结构**：
   - **第一列【岗位】**：展示辅助岗位名称（如收试剂、设备管理、标本转运与外送、室内质控等）及所属专业组/类别标签；
   - **第二列【责任人】**：直接平铺展示在当前时间周期内指派的责任人姓名标签。
2. **A/B 角互备规则（属性化展示，不拆列）**：
   - A 岗与 B 岗属于人员被指派时的**职责角色标识（互备机制）**，**严禁在前端拆分为独立的“A岗列”与“B岗列”**；
   - **A 岗（第一责任人 / 主办）**：该项辅助工作的常态化直接主责人；
   - **B 岗（备选责任人 / 协助 / 替补）**：该项工作的备份托底人。A 岗请假或不在岗时无缝补位顶上，保障工作不停摆；平时协同分担；
   - **单元格展示**：在【责任人】列内以标签带标示方式紧凑呈现（如 `龙其 (A)` `华东 (B)`；单人岗位直接展示 `苡晴`）；
   - **排班编辑交互**：排班管理员在选人下拉框或人员弹窗中为指派人员指定角色标识（A角/B角），界面表格始终保持平整的两列结构。

## 2.3 单日排班弹窗

![图 2-3 单日排班微调弹窗](./images/schedule_features/03_single_day_schedule_modal.png)

### 2.3.1 弹窗字段
1. **排班日期**：单行文本输入框，只读禁用。自动回显所选单元格对应公历日期与星期（格式如 `2026-11-03 周二`）。
2. **岗位名称**：单行文本输入框，只读禁用。自动回显所选单元格对应岗位名称（格式如 `PCR岗 1`）。
3. **所属专业组**：单行文本输入框，只读禁用。自动回显所选岗位所属专业组（格式如 `分子检测组`）。
4. **排班人员**：
   - 控件类型：下拉选择框。
   - 约束说明：必填项。
   - 下拉数据源：严格仅加载排班规则中该岗位胜任人员名单。

### 2.3.2 弹窗操作
1. **【取消】**：
   - 处理逻辑：点击单元格数据保持不变，直接关闭弹窗。
2. **【确定】**：
   - 可用条件：必填项已选。
   - 处理逻辑：点击后按序执行以下业务逻辑：
     - 步骤 1（非空校验）：校验排班人员是否已选，未选提示“请选择排班人员”；
     - 步骤 2（排班日期冲突校验）：校验所选人员在当天是否已排入其他“非兼任”的主岗位。若冲突，弹出 Toast “当前人员排班冲突”，并高亮人员选择框及人员姓名；
     - 步骤 3：校验通过后，关闭弹窗并更新对应单元格排班责任人，弹出成功提示“排班保存成功”。

## 2.4 批量排班弹窗

![图 2-4 批量排班全景工作台](./images/schedule_features/04_batch_schedule_modal.png)

用于月初编制周期底稿、季度核心骨干轮换、物理房间日常轮转等统筹排班场景。点击大看板顶部 `[批量排班]` 唤起。系统遵循“一次批量操作处理一种排班模式；按岗位增量合并生效”的口径。

### 2.4.1 表单字段
1. **排班类型（第一行置顶）**：
   - 控件类型：单选按钮组 (`name="batchSplitType"`)，布局于弹窗首行。
   - 样式规范：已选文字与单选按钮高亮为**蓝色**，未选中为常规灰黑色。
   - 约束说明：必填项，单选互斥。
   - 选项内容：包含 5 种业务模式：时间段固定、每日轮转、按每周、按每月、按季度。
   - **动态联动下方日期选择维度**：
     - **选【按每周】 / 【按每月】**：下方日期控件自动切换为**年月选择器**（仅需选择目标年月，如 `2026-11`），系统根据目标年月自动匹配并展开整月/各周；
     - **选【按季度】**：下方日期控件自动切换为**年份选择器**（仅需选择目标年份，如 `2026年`），系统以此为基准展开 Q1~Q4 四个季度列；
     - **选【时间段固定】 / 【每日轮转】**：下方展示具体的**开始日期、结束日期（年月日维度）**输入框；
       - 选【时间段固定】：起止时间内责任人固定不变，结合【仅工作日】设置自动跳过休假日；
       - 选【每日轮转】：工作日环形错位平移轮转，下方联动显示“轮空天数”字段，明细表切换为配置首日基准人；轮转偏移量严格按系统工作日序列递推。
2. **排班日期范围（第二行动态适配）**：
   - **按每周/按每月模式**：
     - 控件类型：年月选择输入框 (`#batchYearMonth`)。
     - 约束说明：必填项，默认带入当前年月（如 `2026-11`）。
   - **按季度模式**：
     - 控件类型：年份选择输入框 (`#batchYear`)。
     - 约束说明：必填项，默认带入当前年份（如 `2026`）。
   - **时间段固定/每日轮转模式**：
     - **开始时间**：日期选择输入框 (`#batchStartDate`)，必填，默认带入当前周期起始工作日（如 `2026-11-02`）。
     - **结束时间**：日期选择输入框 (`#batchEndDate`)，必填，默认带入当前周期结束日期；结束时间不得早于开始时间。
     - **仅工作日**：复选框 (`#batchWorkdayOnly`)，默认勾选。
       - 勾选时仅向系统日历标记为“上班”的工作日生成排班，非工作日（法定休假及普通周末）自动跳过；
       - 未勾选时全量排入连续自然日，适用于急诊值班或每日连续巡检工位。
3. **轮空天数**：
   - 控件类型：数字输入框 (`#batchRollingRestDays`)。
   - 显示条件：仅在排班类型选中【每日轮转】时动态展示。
   - 约束说明：默认值为 `0`，支持输入正整数。
   - 业务规则：控制技术人员执勤一轮后进入轮空休息的天数，期满后重新补入队列。

### 2.4.2 岗位排班明细表

**表格操作**：
1. **【+ 新增岗位】**：常驻可用。点击打开【岗位选择】穿梭多选弹窗，支持按专业组检索、批量勾选一个或多个岗位并一次性追加至明细表中，自动带出各岗位只读信息及胜任人员池白名单。
2. **【删除】（行操作）**：常驻可用。点击即刻从批量明细表中移除当前行岗位记录，明细表行数与序号自动重新计算。

**表格列定义**：
1. **序号**：
   - 包含内容：系统连续编号 (1, 2, 3...)。
   - 读写权限：只读。
   - 逻辑说明：随行的增加、删除自动重排。
2. **岗位名称**：
   - 包含内容：岗位中文全称（如 `PCR岗 1`）。
   - 读写权限：只读。
   - 逻辑说明：继承岗位字典正式名称，排班时不可修改。
3. **所属专业组**：
   - 包含内容：专业组名称（如分子检测组、取材技术组、常规病理诊断组）。
   - 读写权限：只读。
4. **关联项目/职责**：
   - 包含内容：展示该岗位对应的检测项目或日常职责文本（如 `肺11、肠四联、BRAF`）。
   - 读写权限：只读。
5. **排班人员**：
   - 控件类型：下拉选择框。
   - 读写权限：唯一可编辑列。
   - 下拉数据源：严格仅加载该岗位预设的胜任人员名单（`competent_pool`）。
   - 模式特定含义：在【每日轮转】模式下，该列代表“首日责任人”，系统以此为基准逐日平移。
6. **操作**：
   - 控件类型：`[删除]` 按钮。
   - 读写权限：可操作。
   - 处理逻辑：点击即刻从批量明细表中移除当前行岗位记录，明细表行数与序号自动重新计算。

### 2.4.3 弹窗操作
弹窗底部操作按钮依次为：**【取消】**、**【预览排班】**、**【暂存】**、**【发布排班】**：
1. **【取消】**：
   - 可用条件：常驻可用。
   - 处理逻辑：点击放弃本次批量排班未提交内容，直接关闭弹窗。
2. **【预览排班】**：
   - 可用条件：明细表存在有效记录。
   - 处理逻辑：点击后执行排班推演并打开全景推演预览大弹窗 (`#modalBatchSchedulePreview`)，横向展开所选周期的全部工作日与公休日，直观呈现各岗位派发的人员标签。
     - **推演预览弹窗截图**：
       ![图 2-5 批量排班全周期推演预览弹窗](./images/schedule_features/05_batch_schedule_preview_modal.png)
3. **【暂存】（草稿保存）**：
   - 可用条件：已选择排班类型及对应有效日期。
   - 处理逻辑：
     - 校验当前明细表至少有一行数据；
     - 将当前批量排班数据存为“草稿”版本，不强制拦截兼任互斥等阻断校验；
     - 弹出成功提示“排班草稿已暂存”，关闭弹窗；
     - 排班大盘顶部状态徽章同步联动更新为【草稿】（橙黄色徽章）。
4. **【发布排班】（正式生效，原确认排班逻辑）**：
   - 可用条件：必填项完整且通过强校验。
   - 处理逻辑：点击后按序执行以下严格校验与发布流程：
     - 步骤 1（时间合法性校验）：校验时间非空，且起止范围合法；
     - 步骤 2（明细非空校验）：校验明细表中每一行的排班人员列均已指定人员，未指定项予以定位提示；
     - 步骤 3（同日互斥校验拦截）：系统自动扫描推演结果中每一天的全科人员分布。若同一人员在同一天被排入了两个及以上关闭兼任的岗位，系统强行阻断保存，弹出错误提示并标红冲突行；
     - 步骤 4（数据正式生效写入）：校验通过后，结合【仅工作日】与排班类型，将推演生成的有效排班数据正式写入排班矩阵大盘；
     - 步骤 5（状态与视图更新）：弹出成功提示“排班已成功发布”，关闭弹窗，排班看板即刻刷新为最新已发布公示态，顶部状态徽章联动更新为【已发布】（绿色徽章）。

## 3.2 待办筛选区

## 3.3 待办列表

### 3.3.1 列表字段
1. **[复选框]**：

   - 交互逻辑：勾选状态改变时，实时联动更新列表上方“已选 N 项”计数以及【批量删除】按钮可用状态。
2. **序号**：

3. **岗位名称**：
   - 控件类型：单行文本加粗展示，只读禁用。
   - 包含内容：自动回显排班矩阵中继承的岗位名称（格式如 `PCR岗 1`）。
4. **任务内容**：
   - 控件类型：单行文本展示，只读禁用。
   - 包含内容：自动回显岗位绑定的工作指引、质控任务或辅助事务；超长文本单行截断省略，鼠标悬浮展示完整文本提示。
5. **责任人**：
   - 控件类型：单行文本展示，只读禁用。
   - 包含内容：自动回显排班分配的当班责任人姓名；多人当班以顿号分隔（格式如 `张明、李华`）。
6. **任务开始时间**：
   - 控件类型：单行日期文本展示，只读禁用。

7. **任务结束时间**：
   - 控件类型：单行日期文本展示，只读禁用。
   - 包含内容：自动回显待办周期计划截止日期（格式如 `2026-11-30`）。
8. **任务状态**：
   - 控件类型：状态胶囊徽标展示，只读禁用。
   - 状态标识：
     - `[未开始]`：灰底灰字徽标（`#F4F4F5` / `#909399`）；
     - `[进行中]`：蓝底蓝字徽标（`#ECF5FF` / `#008FD5`）；
     - `[已完成]`：绿底绿字徽标（`#E8FFEA` / `#00B42A`）；
     - `[已超期]`：红底红字徽标（`#FFF0F0` / `#F53F3F`）。
   - 状态判定逻辑：
     - **已完成**：已在行内点击【完成】按钮核销的任务。状态锁定为“已完成”，不再受后续时间流转影响；
     - **未开始**：任务尚未核销，且当前系统日期早于任务开始时间（当前日期 < 任务开始时间）；
     - **进行中**：任务尚未核销，且当前系统日期处于任务计划周期内（任务开始时间 ≤ 当前日期 ≤ 任务结束时间）；
     - **已超期**：任务尚未核销，且当前系统日期已超过计划截止日期（当前日期 > 任务结束时间）。
    - 超期提醒机制：针对已超期未完成任务，系统支持通过参数控制在超期 N 天后自动向责任人发送站内信催办提醒（每条超期任务独立发送一条通知，避免高频打扰）。
9. **操作**：
   - 控件类型：行内快捷操作按钮组。
   - 交互逻辑：
     - 未完成记录（包括：未开始、进行中、已超期）：并排展示 **`[完成]`** 与 **`[查看]`** 按钮（超期任务依然支持补做核销）；
     - 已完成记录：仅保留展示 **`[查看]`** 按钮。

## 3.4 发起排班待办弹窗

![图 3-2 发起排班待办弹窗](./images/schedule_features/07_launch_todo_modal.png)

**触发源**：由排班大看板顶部操作栏中的 **`[发起待办]`** 按钮点击唤起（参见第 2.1.2 节），用于将当前已排好的矩阵网格正式实例化为员工执行待办任务。

### 3.4.1 表单字段
1. **开始时间**：
   - 控件类型：日期选择输入框 (`#launchStartDate`)。

   - 联动规则：修改后**不自动触发下方明细表实时刷新**，防止输入过程中频繁重绘或冲掉已编辑的提醒周期；需在下方明细表区域点击【刷新】按钮手动触发重新加载。
2. **结束时间**：
   - 控件类型：日期选择输入框 (`#launchEndDate`)。
   - 约束说明：必填项，默认带入排班周期结束日期；结束时间不得早于开始时间。
   - 联动规则：修改后**不自动触发下方明细表实时刷新**，防止输入过程中频繁重绘或冲掉已编辑的提醒周期；需在下方明细表区域点击【刷新】按钮手动触发重新加载。

### 3.4.2 任务明细表

**表格操作**：
1. **【刷新】**：
   - 控件样式：线框按钮（无实心填充，仅线框加文字）。
   - 可用条件：常驻可用。
   - 处理逻辑：点击后依据当前表单选定的开始时间与结束时间，重新扫描大盘数据，恢复并重新加载全量有效已排班岗位明细列表，弹出提示“已重新获取当前时间段排班岗位”。
2. **【移除】**：
   - 控件样式：线框按钮（无实心填充，仅线框加文字）。
   - 可用条件：勾选一条或多条任务明细。
   - 处理逻辑：
     - 未勾选点击提示：“请先勾选需要移除的任务明细！”；
     - 已勾选点击即刻将所选任务明细从本次待办发起清单中移除，行数与序号自动重新计算；仅剔除本次待办实例化，不影响底层排班大看板中的排班数据。

**表格列定义**：
1. **[复选框]**：
   - 控件类型：表头全选复选框，各数据行独立复选框。
   - 交互逻辑：勾选单行或多行后，联动上方【移除】操作生效。
2. **序号**：
   - 控件类型：单行文本展示，只读禁用。
   - 包含内容：系统连续编号 (1, 2, 3...)，随行的移除自动重排。
3. **岗位名称**：
   - 控件类型：单行文本加粗展示，只读禁用。
   - 包含内容：动态展示所选时间段内有实际排班人员的岗位中文全称。
4. **所属专业组**：
   - 控件类型：单行文本展示，只读禁用。
   - 包含内容：自动回显岗位所属专业组名称（如 `分子检测组`、`取材技术组`）。
5. **任务明细**：
   - 控件类型：单行文本展示，只读禁用。
   - **单行解耦展示规则**：若一个岗位关联了多个待办任务，**每一个任务均单独显示一行**，不再合并展示。单行仅展示当前单一具体的任务名称。
6. **在岗责任人**：
   - 控件类型：单行文本展示，只读禁用。
   - 包含内容：自动汇总所选时间段内该岗位实际排定的责任人姓名；多人当值以顿号分隔（格式如 `张明、李华`）。
7. **任务周期**：
   - 控件类型：只读文本/标签展示（展示内容：`每日`、`每周`、`每月`）。
   - 读写权限：**只读字段，不允许修改**。
   - 取值规则：严格继承排班规则维护中心中该任务所绑定的固有任务周期属性，发起待办时直接作为实例化周期的唯一依据。

### 3.4.3 弹窗操作
1. **【取消】**：
   - 处理逻辑：点击放弃本次待办发起，直接关闭弹窗。
2. **【确认】**：
   - **步骤 1（任务批量实例化）**：根据各独立任务行的【任务周期】（每日、每周、每月）批量生成待办记录（每日任务逐日生成 1 条，每周/每月任务合并生成 1 条周度/月度任务，责任人关联周期内在岗人员）：
     - 每日任务：按自然日逐日拆解，`开始时间 = 结束时间 = 当天自然日 (YYYY-MM-DD)`，精确提取当天实际排班责任人（轮空无排班日不生成）；
     - 每周任务：按自然周聚合，起止时间为选定周期内该周首末日，自动汇总并去重整周在岗责任人（多人以顿号隔开）；
     - 每月任务：按自然月聚合，起止时间为选定周期内该月首末日，自动汇总并去重当月在岗责任人（多人以顿号隔开）。
   - **步骤 2（调用消息模板并发站内通知）**：系统计算各员工分配的待办总数，支持参数控制是否开启任务待办及消息模板：
     - **最简消息模板**：
       - 模板名称：排班待办履职提醒
       - 模板编码：`TMPL_SCHEDULE_TODO_NOTICE`
       - 消息类型：站内通知（系统消息）
       - 消息标题：排班履职待办提醒
       - 消息内容：`${user_name}技术员，您在 ${cycle} 周期内有 ${todo_count} 项排班待办任务，请按时完成履职与核销。`
   - **步骤 3（任务生成）**：关闭弹窗，并刷新待办任务列表。

### 4.3.2 编辑操作逻辑
1. **【取消】**：
   - 可用条件：处于行编辑状态。
   - 处理逻辑：点击放弃当前行未保存的编辑内容，数据还原为编辑前的值并退出行编辑状态。
2. **【保存】**：
   - 可用条件：处于行编辑状态。
   - 处理逻辑：点击后按序执行以下校验与生效流程：
     - 步骤 1（非空校验）：校验岗位小类名称非空，未填提示“请输入岗位名称”；
     - 步骤 2（专业组校验）：校验所属专业组已选择；
     - 步骤 3（胜任人员校验）：校验胜任人员池至少配置 1 人，未配置提示“胜任人员不能为空，请至少添加一名人员”；
     - 步骤 4（行数据持久化）：校验通过后，持久化当前行数据，切换回只读展示态；
     - 步骤 5（全局联动更新）：点击页面底部【保存配置】按钮后，将规则全量同步生效至全局岗位注册中心 (`POST_REGISTRY`)，排班大盘即刻按最新岗位配置刷新。

# 5. 工作量统计与核算

## 5.1 统计核算与津贴
1. **病理科**：按月统计每位专家的会诊例数、常规/快速切片质控例数及带教阶段津贴报账清单。
2. **分子科**：按月统计人员在各工位的实际轮岗时长、房间出勤率及质控履历，满足实验室绩效核算与追溯要求。
